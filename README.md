# OMNIVERSE

**Alpha 0.1.0 — First Playable**

OMNIVERSE is a browser-based personal planet simulator. Begin with Aurelia, manage its resources, support its biosphere, and watch the world change as simulation years pass.

## Run it
Open `index.html` in a modern browser with an internet connection. The 3D planet uses Three.js from jsDelivr. On GitHub Pages, publish from the `main` branch and the `/(root)` folder.

## Alpha 0.1.0 features
- Interactive 3D planet with orbit/zoom controls
- Water, food, minerals, and energy resources
- Planet development actions
- Simulation clock with pause and 1× / 2× / 4× speed
- Population, biodiversity, temperature, and oxygen indicators
- Local browser save using localStorage
- Responsive layout for phones and desktop

## Current limits
This is a single-player prototype. Saves are stored only in the browser/device where you play. Accounts, cloud saves, separate player universes, multiple planets, and shared exploration are not implemented yet. Do not expect a save to sync between devices or browsers.
