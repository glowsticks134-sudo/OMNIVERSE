# PROJECT VICE

**Early Access 0.1.0 — First Playable Prototype**

A browser-based 3D open-world driving and exploration game. PROJECT VICE is an original game inspired by the scale and freedom of modern open-world adventures.

## Play

After GitHub Pages publishes the repository, open:

https://glowsticks134-sudo.github.io/OMNIVERSE/vice/

## Controls

- **WASD / arrow keys:** Move or drive
- **E:** Enter or exit the nearby car
- **C:** Switch between third-person and first-person camera
- **Mouse drag:** Look around
- **Mobile:** Use the on-screen movement buttons and action buttons

## 0.1.0 features

- 3D coastal city prototype
- Walkable player character
- Drivable vehicle with arcade handling
- Third-person and first-person camera modes
- Basic traffic and palm-lined streets
- Desktop and mobile touch controls

## Roadmap

- Better vehicle physics and additional vehicles
- More detailed city districts and interiors
- Pedestrian AI and traffic rules
- Mission system and story
- Police response and wanted levels
- Character, vehicle, and property customization
- Save system

This is an early prototype, not a full-scale commercial open-world game. Features will be added in stages.
